## Overview

**Luxe Heritage** is a mobile-first UI/UX prototype that simulates a complete luxury hospitality workflow, from the moment a guest browses a villa to the moment they check out. The project's focus is interaction design and visual consistency rather than backend functionality — every screen was built to demonstrate a coherent, production-quality design system rather than a fully functional booking engine.

---

## Features

- **Villa Browsing & Booking** — a guided flow for exploring and reserving a villa
- **Room Service Ordering** — an in-stay ordering interface for guest requests
- **Digital Boarding Pass & Smart Key** — a contactless check-in and room-access experience
- **Design Token System** — documented colors, typography scale, and spacing units, applied consistently across every screen

---

## Design Approach

The prototype was built around a single, documented design system rather than one-off screen styling. Every color, typeface, and spacing value used in the interface is defined as a reusable design token, so the visual language stays consistent as the prototype grows — the same approach used in production design systems.

## Getting Started

### Prerequisites
- Node.js installed
- A Gemini API key

### 1. Clone the Repository

git clone https://github.com/AllanJenisha10/Allanjenisha_Luxe_Heritage_UIUX-Prototype.git
cd Allanjenisha_Luxe_Heritage_UIUX-Prototype

### 2. Install Dependencies

npm install

### 3. Configure Environment Variables

Copy .env.example to .env.local and add your key:

GEMINI_API_KEY=your_key_here

### 4. Run Locally

npm run dev

## Purpose
