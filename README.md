# 🏨 LuxeStay & Le Bistro — Mobile UI/UX Prototype

An interactive, production-grade mobile application prototype designed and engineered for a luxury heritage hospitality brand in Puducherry. It bridges high-fidelity UI/UX design specifications into a responsive web application running inside an interactive smartphone device chassis.

---

### ✨ Key Features

- **📱 Interactive Mobile Frame Simulator**: Experience the mobile app in an interactive device frame with multiple finishes (Titanium Black, Desert Sand Gold, Natural Silver) or switch into edge-to-edge fullscreen view.
- **🏝️ Starting Node 1:3 Welcome Experience**: Onboarding splash with brand storytelling, French-Tamil heritage visuals, and rapid prototype flow initialization.
- **🏡 Curated Stays & Villa Exploration**:
  - Filter by aesthetic districts (*French Quarter*, *Beachfront*, *Heritage Villas*, *Wellness Havens*).
  - Search by amenities and property names.
  - Interactive wishlist favoriting.
- **🛎️ Architectural Suite Details & Booking Engine**:
  - Multi-image gallery with selectable photo thumbnails.
  - Key specifications (guest capacity, bedrooms, en-suite bathrooms, square footage).
  - Dynamic stay duration calculator with tax calculations and instant reservation confirmation.
- **🎫 Digital Boarding Pass & Smart Key**:
  - Airline/luxury boarding pass layout with unique confirmation codes (`LX-XXXXXX`), check-in/out timestamps, digital QR code pass, and haptic confetti feedback.
- **🍽️ Le Bistro & In-Room Gourmet Dining**:
  - Categorized French-Creole menu (Starters, Mains, Desserts, Beverages) with dietary tags and calorie counts.
  - Live room service cart with suite/table selection, gratuity options, and order placement.
- **🛎️ 24/7 Heritage Butler Concierge**:
  - Book signature local excursions (promenade cycling, seaside candlelight dining, Ayurvedic treatments).
  - Interactive simulated live butler desk chat assistant.
- **🎨 UI/UX Design System Spec & Tokens**:
  - Dedicated drawer displaying chromatic palettes, WCAG 2.1 AA compliant contrast ratios, Playfair Display & Plus Jakarta Sans typographic scales, and 4px baseline spatial grids.
- **🔗 Figma Bridge & Hotspot Engine**:
  - Live modal to inspect Figma prototype node references and connect via the Figma REST API.
  - Custom hotspot player with interactive visual hints.

---

### 🛠️ Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations & Effects**: Motion (`motion/react`), Canvas Confetti
